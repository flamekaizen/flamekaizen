<details>
<summary><b>🔬 Methodology — how these numbers are computed</b></summary>
<br/>

<div align="left">

| Metric | Definition |
|:--|:--|
| **7-day MA / 28-day EMA** | Simple moving average and exponential smoothing (α = 2/29) of daily contribution counts |
| **OLS trend** | Ordinary least-squares fit over the last 12 complete months; slope in contributions/month, with R² |
| **Duty cycle** | Share of the trailing 365 days with ≥ 1 contribution |
| **Gini index G** | Inequality of daily output — 0 = perfectly even, 1 = all work on a single day |
| **Burstiness B** | Goh–Barabási `(σ − μ)/(σ + μ)`: −1 periodic, 0 Poisson-random, +1 extremely bursty |
| **ρ₁ autocorrelation** | Lag-1 autocorrelation — do active days cluster together? |
| **Weekday entropy H** | Shannon entropy of the weekday distribution normalised by log₂7 — 1 = perfectly uniform week |
| **Language spectrum** | Each repository carries equal weight, split by its byte fractions — one huge notebook can't drown out everything else |

Data: GitHub GraphQL API (full contribution calendar since account creation). Source: [`scripts/generate_analytics.py`](scripts/generate_analytics.py). Private repositories only ever feed aggregate numbers — no names are published.

</div>
